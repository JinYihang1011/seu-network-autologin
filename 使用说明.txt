SEU 校园网自动登录 —— 使用说明（三步）
========================================

第 1 步：首次配置并测试
    双击  1-首次配置并测试.cmd
    - 会问三个问题：一卡通、密码（校园网和宽带是同一个）、有没有运营商宽带
      没有运营商宽带（只有校园网 SEU-WLAN）就直接回车
    - 它会自动生成 config.json，并立刻试一次认证
    - 看到「认证完成，外网已连通」就说明成功了

第 2 步：安装开机自动登录
    双击  2-安装开机自启.cmd
    - 弹出 UAC（用户账户控制）窗口时点「是」
    - 装好后：
        * 开机（锁屏阶段）自动认证
        * 登录 Windows 后再兜底一次，之后每 15 分钟检查一次
        * 切换网络（比如从 SEU-ISP 换到 SEU-WLAN）后会自动补认证
    - 同时会关掉 Windows 那个「登录到网络」弹窗（见下面「关于那个弹窗」）

第 3 步（可选）：出问题看日志
    login.log —— 每次运行的结果都在里面，第一眼看这个

----------------------------------------
关于那个「登录到网络」弹窗（装任务时会自动关掉）

以前每次连上校园网，Windows 都会弹一个「需要操作 / 登录到网络」的提示、
还会自己打开浏览器跳到登录页。那是因为 Windows 自己会去探测外网（用的是
    http://www.msftconnecttest.com/connecttest.txt
这个网址），而校园门户把它劫持到登录页，Windows 就以为「这个热点需要登录」。
本工具认证只要 1 秒左右，弹窗却比它更早，所以你看到的是
「明明已经自动登录了，浏览器还是弹了一下」。

第 2 步装任务时会自动把 Windows 这项探测关掉，所以以后不会再有这个弹窗。
（本工具自己校验外网用的是同一个网址，认证结果不受任何影响。）

代价：Windows 不再判断「这个网络需不需要登录」。万一哪天认证没成功
（密码改了、开着 Clash 的 TUN、门户改版），托盘图标可能仍显示已连接，
也不会弹窗提醒你 —— 这时请看 login.log。

想恢复弹窗：双击  4-恢复联网验证弹窗.cmd
想再关掉：  双击  3-关闭联网验证弹窗.cmd
（两个都要在 UAC 窗口点「是」；做完直接关掉那个窗口就行）

----------------------------------------
让校园网能自动连上（很重要）

这个工具负责"认证"，但前提是 Windows 先把 WiFi 连上。
检查：设置 → 网络和 Internet → WLAN → 管理已知网络 → 点开 SEU-WLAN / SEU-ISP
      → 勾上「在范围内时自动连接」
（管理员 PowerShell 里的等价命令）
      netsh wlan set profileparameter name="SEU-WLAN" connectionmode=auto
      netsh wlan set profileparameter name="SEU-ISP"  connectionmode=auto

如果手机热点也设了自动连接，且排在校园网前面，电脑会优先连热点；
在"管理已知网络"里把它上移/下移，或用
      netsh wlan set profileorder name="SEU-ISP" interface="WLAN" priority=1
把校园网提到前面。

----------------------------------------
注意事项

1. 首次运行 exe 会弹 SmartScreen「未知发布者」，点「更多信息 → 仍要运行」。
   这是因为 exe 没有买代码签名证书，不是病毒。
2. 把这个文件夹放在**固定的位置**（别放会被清理的临时目录），
   config.json（你的账号密码）和 login.log 都存在这里。
3. config.json 里是明文密码，只存在你本机，不要发给别人、也不要传到网上。
4. 开着 Clash 的 TUN 模式会劫持去认证门户的路由，认证会失败 —— 用之前先关掉 TUN。
5. SEU-WLAN 和 SEU-ISP 用的是同一个一卡通号和同一个密码，填一次就行。

----------------------------------------
想卸载（管理员 PowerShell 执行）

    Unregister-ScheduledTask -TaskName 'SEU-ISP-AutoLogin' -Confirm:$false
    Unregister-ScheduledTask -TaskName 'SEU-ISP-AutoLogin-Boot' -Confirm:$false

卸载后如果想把 Windows 的联网验证弹窗也恢复原样，双击
    4-恢复联网验证弹窗.cmd
